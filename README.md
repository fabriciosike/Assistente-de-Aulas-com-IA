# 🤖 Assistente de Aulas com IA

> Um assistente inteligente desenvolvido em Python para otimizar a sua rotina acadêmica, ajudando a identificar aulas em andamento, consultar horários, professores e prever a próxima aula de cada disciplina com rapidez e precisão.

---

## 🚀 Funcionalidades

- **Aulas do Dia:** Identifica instantaneamente quais aulas estão acontecendo na data atual.
- **Próxima Aula:** Informa com antecedência quando será o próximo encontro de cada disciplina.
- **Consulta Rápida:** Facilita a busca por horários de aulas e informações sobre os professores.
- **Prático e Preciso:** Desenvolvido para organizar o seu dia a dia acadêmico sem complicações.
